# Original hardware vectors

`ppc-ni-603-normal.txt` contains 816 result/FPSCR pairs captured on the user's
Macintosh 5260/100, 603-family PowerPC, System 7.5.5, on 2026-10-29. They were produced
by `../mac-ni-reference.py` and decoded with its `--decode-binary` option. The
probe is original PPC code; these numerical results contain no Apple software.
The decoded capture's original binary SHA-256 is
`98b894c2347412c5c2d31e196db59c745fa8cdc5acc21245076ca668499d38c1`.

Each row contains hexadecimal opcode, FRA, FRB, FRC, incoming FPSCR, result and
outgoing FPSCR. Cases cover normal inputs or zero, both signs, four rounding
modes, NI off/on, single/double arithmetic and FRSP. The table includes tiny
values rounded up to minimum-normal in IEEE mode but flushed in NI mode.

These operands deliberately avoid the 603/750 difference for denormal input
operands. They do not establish 750 NI operand handling, UE-enabled result
scaling, estimate tables or floating-point trap delivery. The fixture exercises
the shared NI result behavior; the MPC750 manual remains the target reference.

`ppc-ni-603-underflow-enabled.txt` repeats the 816 cases with UE set, on the
same Mac and date. Both NI settings retain the scaled result and update UX/FEX;
NI's signed-zero result flush applies when UE is clear. The capture's binary
SHA-256 is `cd5d753a5fe429008a8156f15ca42e9fb578b6d24e53e98e5d851e37cb25fb18`.
The Mac's normal application floating-point exception mode was retained; these
results validate value/FPSCR behavior, not MSR-controlled trap delivery.

`ppc-fres-603-powers.txt` contains 2,496 normal exact-power FRES cases from the
same Mac and date, generated by `../mac-reciprocal-reference.py`. They cover
signs, rounding modes, NI and OE/UE around normal/tiny/scaled boundaries. The
original binary SHA-256 is
`3444b65a30efeefa25a959bca7cb942a3f0d5ea06794d71cde1a1d2b385400a8`.

General estimate bits are implementation-dependent. This subset compares exact
power results and selected status fields. FR/FI are architecturally undefined;
the 603 capture also sets XX on some range paths, unlike the documented target
policy. All three bits are excluded from this hardware comparison. Independent
estimate tests require XX preservation, including NI result flushing, and check
the full finite exponent range. These vectors do not establish a 750 estimate
table or denormal-operand NI behavior.

`ppc-conversion-603-normal.txt` contains 864 FCTIW/FCTIWZ cases from the same
Mac and date, generated by `../mac-conversion-reference.py`. Normal inputs,
zero, infinities, signaling/quiet NaNs, both signs, integer-range boundaries,
all rounding modes and NI off/on are covered. The capture's binary SHA-256 is
`d41e9092769a75e88e0bad9970ec3aff032befdc96a9af6279725a8fb7ef2de1`.
Compare only the low 32 result bits; the high word is architecturally undefined.
All FPSCR bits are compared, including preserved FPRF. Instruction replay adds
destination aliases, record forms and both dispatch settings. VE is clear in
this capture; enabled-invalid inhibition has separate synthetic tests. These
vectors do not validate denormal-input NI behavior or MSR trap delivery.
